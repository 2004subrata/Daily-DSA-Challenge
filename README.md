## 🚀 How to Use / Clone

Get started in just a few steps:

```bash
# Fork via GitHub UI, then clone your fork

# 1. Clone the repository
git clone https://github.com/yourusername/daily-dsa-challenge.git

# 2. Navigate into the project
cd daily-dsa-challenge

# 3. Open in VS Code
code .
```

> 💡 Each solution is organized by topic/day inside its own folder.
